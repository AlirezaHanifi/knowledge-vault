Multimethod dispatch

A multimethod is a dispatch function plus a table of methods keyed by the values it emits. Emit the type and you have single dispatch; emit two types for multiple dispatch; emit anything computed, like whether a name is long, for dynamic dispatch. New methods can be added anywhere, without editing the others.

Illustrates sections 13.2–13.4 (figures 13.1–13.4; listings 13.6–13.20, pp. 277–288): greet with single dispatch and a default, greetLang on [animal type, language type], and dysGreet on [animal type, name length > 5]. Animals, languages and greetings are the book’s; the horse method and the error text are the vault’s. Implementation is the vault’s own.

    What to notice
    
  
      
    
    • The dispatch value is just data: a string, an array of two strings, or an array with a Boolean. The table is a hash map from those values to methods.
      • 
    
    • Extending is adding a row: the default and the horse method are new registrations; the dog, cat and cow methods are never edited.
      • 
    
    • No match and no default means an error. Try Horace with greetLang or dysGreet, which have no default.
