میدان بازی JSON Schema

در DOP طرح از نمایش جداست: داده mapی خالی است، و طرحی که خودش تنها داده است می‌گوید چه شکلی باید داشته باشد. بر مرزهای سیستم اعتبارسنجی کنید و ریز گزارش دهید چه غلط شد.

تصویری از بخش‌های ۷.۲ و ۷.۳ و ۷.۵ (listingهای ۷.۲ تا ۷.۲۳، صص. ۱۴۴–۱۵۹): طرح درخواست و پاسخ جست‌وجو، پاسخ پایگاه داده با و بی additionalProperties: false، و ریز خطاهای Ajv. آن اعتبارسنج زیرمجموعه‌ی کوچک vault از JSON Schema است، نه Ajv؛ و پیام‌هایش از Ajv تقلید می‌کند. پیاده‌سازی مال خود vault است.
