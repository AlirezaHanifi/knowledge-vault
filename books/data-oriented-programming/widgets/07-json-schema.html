اعتبارسنجی با JSON Schema

در DOP schema از نمایش داده جداست: داده یک map معمولی است و schema، که خودش هم داده است، می‌گوید داده باید چه شکلی داشته باشد. داده را در مرزهای سیستم اعتبارسنجی کنید و دقیق گزارش بدهید چه چیزی اشتباه است.

تصویری از بخش‌های ۷.۲، ۷.۳ و ۷.۵ (صص. ۱۴۴–۱۶۰): schema درخواست جست‌وجو (listingهای ۷.۵ تا ۷.۹)، پاسخ جست‌وجو (listing ۷.۱۱)، پاسخ پایگاه داده با و بدون additionalProperties: false (listingهای ۷.۱۴ و ۷.۱۵) و جزئیات خطاهای Ajv (listingهای ۷.۲۱ تا ۷.۲۳). اعتبارسنج زیرمجموعه‌ی کوچکی از JSON Schema است که vault نوشته، نه خود Ajv، و پیام‌هایش را از Ajv تقلید می‌کند.
