ISBN composition

An Open Library response always has isbn_10, isbn_13 or both: books published before 2007 have the first, later ones the second, and republished books like Watchmen both. Theo’s rule is basic AND (isbn13 OR isbn10): in JSON Schema, allOf and anyOf.

Illustrates section 7.4, Schema composition (listings 7.16–7.19, pp. 154–157). The response is listing 7.16’s Watchmen; the oneOf comparison follows the book’s remark that oneOf exists, and the truth table is the vault’s. Implementation is the vault’s own.
