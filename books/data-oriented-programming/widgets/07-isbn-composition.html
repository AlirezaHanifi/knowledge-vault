ترکیب ISBN

هر پاسخ Open Library دست‌کم یکی از isbn_10 و isbn_13 را دارد و Watchmen هر دو را. قاعده‌ی تئو basic AND (isbn13 OR isbn10) است که در JSON Schema می‌شود allOf و anyOf.

تصویری از بخش ۷.۴، ترکیب schema (صص. ۱۵۴–۱۵۷): پاسخ Watchmen از listing ۷.۱۶ (ص. ۱۵۴)، قاعده‌ی ۲۰۰۷ (ص. ۱۵۵)، schema ترکیبی listing ۷.۱۸ (ص. ۱۵۶) و یادداشت کتاب درباره‌ی oneOf (ص. ۱۵۷). حذف فیلدها، آزمایش oneOf و جدول ترکیب‌ها از vault است. اعتبارسنج زیرمجموعه‌ی کوچکی از JSON Schema است که vault نوشته است.

ترکیب schemaها: bookInfoSchema (listing ۷.۱۸)

به چه چیزی دقت کنید

    
    
      
  • allOf یعنی AND: schema پایه باید برقرار باشد، که فیلد اجباری title هم جزو آن است.
    • 
      
  • anyOf یعنی OR: یک ISBN یا هر دو قبول است؛ همان قاعده‌ای که تئو می‌گوید.
    • 
      
  • oneOf یعنی «دقیقاً یکی»: با آن، Watchmen رد می‌شد، چون هر دو ISBN را دارد.
