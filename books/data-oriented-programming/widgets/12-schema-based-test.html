تست‌های طرح‌محور

با طرحی برای آرگومان‌ها و طرحی برای مقدار بازگشتی، تستی unit خودش را می‌نویسد: داده‌ی تصادفی بسازید که با طرح ورودی می‌خواند، آن تابع را صدا بزنید، و خروجی را با طرح خروجی بسنجید. catalogهای تصادفی نویسنده‌هایی را گواه می‌آورند که نیستند، و اشکالی که آن تست می‌یابد درست همان است.

تصویری از بخش ۱۲.۵ (شکل ۱۲.۳؛ listingهای ۱۲.۱۹ تا ۱۲.۲۹، صص. ۲۶۲–۲۶۸): داده‌ی تصادفی از JSON Schema Faker، تستی که درست یا غلط برمی‌گرداند، پرسشی ساخته از حرف نخست عنوان کتاب نخست، آن خطای log‌شده، و چاره‌ی "Not available". سازنده‌ی این‌جا بدلی کوچک از vault برای JSON Schema Faker است: واژه‌های سبک lorem، با seed، با یک تا چهار کتاب. پیاده‌سازی مال خود vault است.
