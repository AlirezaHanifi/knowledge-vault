تست‌های schema-based

وقتی تابعی برای آرگومان‌ها و مقدار بازگشتی‌اش schema دارد، unit test تقریباً خودش نوشته می‌شود: داده‌ی تصادفی بسازید که با schema ورودی می‌خواند، تابع را صدا بزنید و ببینید خروجی با schema خروجی می‌خواند یا نه. همین تست ساده در کتاب باگی واقعی پیدا می‌کند: نویسنده‌هایی که در catalog نیستند.

تصویری از بخش ۱۲.۵ (شکل ۱۲.۳، listingهای ۱۲.۱۹ تا ۱۲.۲۹، صص. ۲۶۲–۲۶۸): JSON Schema Faker، تستی که true یا false برمی‌گرداند، query ساخته از حرف اول عنوان کتاب اول، خطای log‌شده و اصلاح "Not available". سازنده‌ی داده این‌جا بدل کوچکی از vault برای JSON Schema Faker است: واژه‌های lorem، با seed و یک تا چهار کتاب. اجرای ۲۰۰ seed و پیاده‌سازی از خود vault است.
