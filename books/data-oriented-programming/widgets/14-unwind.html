Unwind and group

To group book items by library, each item needs its book’s title and ISBN. unwind(map, field), after MongoDB’s $unwind, returns one copy of the map per element of the array field, with the field set to that element. Then groupBy on bookItems.libId does the rest.

Illustrates section 14.4 (figure 14.2; listings 14.16–14.19, pp. 305–309): the expected result, the business logic with flatMap, unwind and _.groupBy, and unwind’s implementation with _.map and _.set. The extra item and the mutating-set comparison are the vault’s (see the vault note on p. 309 in the lesson). Implementation is the vault’s own.

The code (listings 14.17 and 14.19)
function unwind(map, field) {
  var arr = _.get(map, field);
  return _.map(arr, function(elem) {
    return _.set(map, field, elem);
  });
}
var bookItems = flatMap(books, function(book) {
  return unwind(book, "bookItems");
});
_.groupBy(bookItems, "bookItems.libId");

    What to notice
    
  
      
    
    • Each unwound map keeps everything else: isbn and title ride along with each single item.
      • 
    
    • No cloning is needed because the data is immutable: _.set returns a new map each time and the original book is untouched.
      • 
    
    • With a mutating set, every “copy” is the same object, so all of them show the last item and the grouping collapses into one library.
