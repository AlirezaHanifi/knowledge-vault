باز کردن و گروه کردن

برای گروه کردن نسخه‌های کتاب با کتابخانه، هر نسخه‌ای عنوان و ISBN کتابش را می‌خواهد. تابع unwind(map, field)، به پیروی از $unwind در MongoDB، برای هر عضوی از آن فیلد آرایه‌ای یک کپی از آن map برمی‌گرداند، با فیلدی که روی همان عضو گذاشته شده. بعد groupBy روی bookItems.libId باقی را می‌کند.

تصویری از بخش ۱۴.۴ (شکل ۱۴.۲؛ listingهای ۱۴.۱۶ تا ۱۴.۱۹، صص. ۳۰۵–۳۰۹): خروجی چشم‌داشته، منطق کسب‌وکار با flatMap و unwind و _.groupBy، و پیاده‌سازی unwind با _.map و _.set. نسخه‌ی افزوده و سنجش set mutationی مال vault است؛ کادر vault در ص. ۳۰۹ درس را ببینید. پیاده‌سازی مال خود vault است.

آن کد (listingهای ۱۴.۱۷ و ۱۴.۱۹)
function unwind(map, field) {
  var arr = _.get(map, field);
  return _.map(arr, function(elem) {
    return _.set(map, field, elem);
  });
}
var bookItems = flatMap(books, function(book) {
  return unwind(book, "bookItems");
});
_.groupBy(bookItems, "bookItems.libId");
