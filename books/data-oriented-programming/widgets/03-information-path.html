Information paths

In DOP every piece of information has an information path, like a file path whose names are nested entities. One generic function, _.get, retrieves any of them, because the path is just data: you can store it in a variable and pass it around.

        What to notice

        • A path mixes strings and integers: map keys for records and indexes, positions for arrays.
        • A missing key ends the walk with undefined, without throwing; that is how _.get behaves (Lodash also accepts a default value).
        • The path is a first-class value. The buttons on the right are just arrays; the same few lines of code resolve every one of them.
