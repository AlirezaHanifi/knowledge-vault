جست‌وجو به‌شکل دست‌کاری داده

جست‌وجوی جو چهار تابع کوچک است و هیچ کلاسی ندارد: با _.get کتاب‌ها را می‌گیرد، با _.filter بر اساس عنوان صافی می‌کند، با _.map هر کتاب را به یک map ساده‌ی bookInfo تبدیل می‌کند و خروجی را JSON.stringify می‌کند. تور خروجی هر مرحله را نشان می‌دهد.

تصویری از بخش ۳.۴، حساب کردن نتیجه‌های جست‌وجو (listingهای ۳.۱۰ تا ۳.۲۴، صص. ۵۸–۶۴)، با Watchmen از listing ۳.۵. دو کتاب اضافه، نمای مرحله‌به‌مرحله و آزمایش فیلد اضافه از vault است. پیاده‌سازی از خود vault است.

تابع Library.searchBooksByTitleJSON(libraryData, query): قاب آبی مرحله‌ی فعلی است و مرحله‌های کم‌رنگ هنوز اجرا نشده‌اند.

جست‌وجو

به چه چیزی دقت کنید

  • هر مرحله داده می‌گیرد و داده می‌دهد، پس هر مقدار میانی را می‌شود دید. سریالی کردن خروجی هم کدی نمی‌خواهد، چون خروجی از اول شکل JSON دارد.
  • اضافه کردن فیلد به کتاب‌ها چیزی را در جست‌وجو عوض نمی‌کند: bookInfo فقط title، isbn و authorIds را می‌خواند. مدل داده انعطاف دارد.
  • روی دیگر سکه ایمنی است: نویسنده‌ای را حذف کنید و جست‌وجو بی‌صدا به جای نامش null برمی‌گرداند. فصل‌های ۷ و ۱۲ برای همین schema اضافه می‌کنند.
