Search as data manipulation

Joe’s search is four small functions and no classes: _.get the books, _.filter by title, _.map each to a BookInfo map literal, and JSON.stringify the result. “The code contains no abstractions. It’s just data manipulation!”

      What to notice

      • Each stage is data in, data out, so you can look at any intermediate value, and serializing the result needs no code: it is already JSON-shaped.
      • Adding a field to books changes nothing in the search: authorNames reads only authorIds, and bookInfo picks only title and isbn. The data model is flexible.
      • The flip side is safety: remove an author and the search returns null where a name should be, silently. Chapters 7 and 12 add schemas for that.
