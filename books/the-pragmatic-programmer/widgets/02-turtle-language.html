A turtle-graphics mini-language

Exercise 4 asks for a parser for a tiny external language of single-letter commands, some followed by a number, designed so that new commands are simple to add. A table that maps each letter to its argument rule and its action keeps the parser itself tiny.

Illustrates Topic 14, Domain Languages, Exercise 4 (pp. 130–131): P selects a pen, D and U put it down and up, and N, E, S, W draw in a direction (in centimetres). The diagonal command, the canvas scale and the error messages are the vault’s. Implementation is the vault’s own; the book’s possible answer is in its appendix.

    What to notice

    • The parser never changes when you add X: one new row in the table is enough. That is the “simple to add new commands” design the exercise asks for.
    • Errors are per line: an unknown letter or a missing or extra argument is reported with its line number, and the rest of the program still runs.
    • Comments after # are stripped first, exactly as in the book’s example program.
