Page replacement: FIFO, LRU, CLOCK, LFU

When the buffer pool is full, a page must be evicted before another can be read. FIFO evicts the oldest arrival, even the B-Tree root that every lookup needs. LRU evicts the least recently used page. CLOCK approximates LRU with one access bit per frame and a sweeping hand. LFU evicts the least frequently used page.

Illustrates “Page Replacement” (pp. 85–88). The reference strings are the vault’s, except the Bélády string 1 2 3 4 1 2 5 1 2 3 4 5, the standard example of the anomaly. LFU ties are broken by evicting the earliest-loaded page. Implementation is the vault’s own.

    What to notice

    • Bélády’s anomaly. With the Bélády string, FIFO makes 9 faults with 3 frames and 10 with 4: more memory, more misses. LRU never does this.
    • FIFO evicts hot pages. In the B-Tree string every lookup touches the root R, yet FIFO evicts it as soon as it is the oldest arrival.
    • CLOCK gives second chances. The hand clears a set bit and moves on; a page is evicted only when the hand finds its bit already cleared.
    • Scans pollute recency. In the scan string, a one-off pass over many leaves pushes the hot pages out of LRU, while LFU keeps them because they were used often.
