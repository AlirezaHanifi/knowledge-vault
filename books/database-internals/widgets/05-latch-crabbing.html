Latch crabbing down a B-Tree

Latch crabbing (latch coupling) lets many threads use a B-Tree at once. A thread latches the root, then moves down like a crab: it latches the child before letting go of the parent. It releases every ancestor as soon as the child is safe, meaning the operation can’t change the structure above it. For a read, every child is safe. For an insert, a child is safe if it isn’t full; for a delete, if it won’t underflow.

    What to notice

    • Reads hold at most two latches. Latch the child, release the parent, all the way down.
    • Insert into a node with room: the parent is released as soon as the child is latched and found not to be full.
    • A full child keeps its ancestors latched, because a split there might propagate into them. The insert of 13 keeps the whole path latched: the leaf and its parent are full.
    • Deletes mirror inserts. A child that holds only the minimum number of keys could underflow and force a merge, so its parent stays latched.
