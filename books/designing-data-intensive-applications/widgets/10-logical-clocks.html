کتابخانه/ DDIA/ فصل ۱۰/ مفهوم logical clock

مرتب کردن رویدادها: ساعت دیواری، Lamport clock و vector clock

یک پاسخ هرگز نباید پیش از پیامی که به آن جواب می‌دهد قرار بگیرد. timestamp ساعت دیواری با skew این را خراب می‌کند. Lamport clock همیشه علت را پیش از معلول می‌گذارد، و vector clock علاوه بر آن می‌گوید کدام پیام‌ها concurrent بوده‌اند.

برای صص. ۴۱۷–۴۲۲ و شکل ۱۰-۹، با چت Aaliyah و Bryce و Caleb کتاب. اختلاف ساعت‌ها، latency تحویل و متن پیام‌ها مال خود vault است.

وضعیت

شبکه

با دکمه‌های «ارسال» و «پاسخ» در کارت هر نفر پیام بفرستید.

به چه چیزی دقت کنید

  • ساعت دیواری ترتیب علّی را می‌شکند. وقتی ساعت Bryce کند است، پاسخش برچسبی زودتر از پیام Aaliyah می‌خورد؛ با رنگ قرمز در فهرست اول.
  • مدل Lamport یعنی زوج (counter, node). هر دو پیام اول counter یک می‌گیرند؛ Bryce که ۱ را دیده، پاسخش را با ۲ برچسب می‌زند. تساوی با اسم node شکسته می‌شود: (1, Aaliyah) < (1, Caleb) < (2, Bryce) (ص. ۴۲۱).
  • ترتیب کامل، نه تشخیص concurrency. مفهوم Lamport timestamp پیام‌های concurrent را دلبخواهی مرتب می‌کند؛ vector clockها نشان می‌دهند پیام‌های Aaliyah و Caleb concurrent بوده‌اند، با رنگ کهربایی (ص. ۴۲۲).
  • هزینه‌ی vectorها. هر vector clock برای هر node یک counter دارد؛ برای سه نفر خوب است و برای هزاران node سنگین (ص. ۴۲۲).
