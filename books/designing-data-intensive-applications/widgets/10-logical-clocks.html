فصل ۱۰ · مفهوم consistency و consensus

مرتب کردن رویدادها: ساعت دیواری، Lamport clock و vector clock

یک پاسخ هرگز نباید پیش از پیامی که به آن جواب می‌دهد قرار بگیرد. timestampهای ساعت دیواری وقتی ساعت‌ها skew دارند ممکن است این را اشتباه کنند. یک Lamport clock، یعنی شمارنده‌ای که هر وقت عدد بزرگ‌تری ببیند به آن می‌پرد، همیشه علت را پیش از معلول می‌گذارد؛ و vector clock علاوه بر این می‌گوید کدام پیام‌ها concurrent بوده‌اند.

برای بخش «مولدهای ID و logical clockها»، از جمله Lamport timestamp و مقایسه‌ی Lamport و hybrid logical clock با vector clock، در صص. ۴۱۷–۴۲۲ و شکل‌های ۱۰-۸ و ۱۰-۹، با چت Aaliyah و Bryce و Caleb کتاب. اختلاف ساعت‌ها، latency تحویل و متن پیام‌ها مال خود vault است. پیاده‌سازی مال خود vault است.

گزارش رویدادها

    به چه چیزی دقت کنید

    • ساعت دیواری ترتیب علّی را می‌شکند. وقتی ساعت Bryce کند است، پاسخش برچسبی زودتر از پیام Aaliyah می‌خورد؛ با رنگ قرمز در فهرست اول.
    • مدل Lamport یعنی زوج (counter, node). هر دو پیام اول counter یک می‌گیرند؛ Bryce که ۱ را دیده، پاسخش را با ۲ برچسب می‌زند. تساوی با اسم node شکسته می‌شود: (1, Aaliyah) < (1, Caleb) < (2, Bryce).
    • ترتیب کامل، نه تشخیص concurrency. مفهوم Lamport timestamp پیام‌های concurrent را دلبخواهی مرتب می‌کند؛ vector clockها نشان می‌دهند پیام‌های Aaliyah و Caleb concurrent بوده‌اند، با رنگ کهربایی.
    • هزینه‌ی vectorها. هر vector clock برای هر node یک counter دارد؛ برای سه نفر خوب است و برای هزاران node سنگین (ص. ۴۲۲).
